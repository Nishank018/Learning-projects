Hard Protocols

Rules to prevent schedule collapse.

Behavioral Code

  • R1. No Plan Rewrites. Execution over planning. No new YouTube strategies.
  • R2. Paper-First PYQs. Solve on paper, timed, without looking at solutions mid-set.
  • R3. Accountability Gate. If PYQ accuracy < 75%, error log is mandatory. No exceptions.
  • R4. Zero Blank Days. If the terminal is not updated by midnight, the day is a failure.

⚠️ The "Compress" Protocol

Trigger: Video Editing Workload.
Action: Activate system toggle. FSD blocks are dropped entirely. 14:00 - 18:00 reallocated to editing. GATE morning blocks remain untouchable.

🔋 The "Minimum Viable" Protocol

Trigger: Sickness or extreme fatigue.
Action: Swap GATE "Deep Dive" for passive reading. Swap PYQs for reading the Error Log. Swap FSD Build for tutorial watching.

🚨 The "Debt Repayment" Protocol

Trigger: A complete zero-day.
Action: Do NOT double up tomorrow. Stay on schedule. Reclaim the missed topic during Sunday's buffer window.
